# MiniEGEGame

Рабочий тренажёр правописания слов из приложенного PDF. Интерфейс повторяет [геймдизайн](docs/game-design.md) и стиль [образца `mainTask7.html`](docs/reference/mainTask7.html) (оригинал сохранён без изменений).

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000/`. Зависимости и сборка не нужны. Данные находятся в `data/words.js`, состояние хранится в `localStorage` браузера.

## Что умеет

- 538 словоформ из списка (включая «фигурист» и «фигуристка» из записи «фигурист(ка)»), по четыре карточки за подход; выбор буквы или ввод слова по маске.
- Проверка с подсветкой и статистикой, подсказки для смысловых пар, модальное окно особых случаев.
- Словарь с поиском, фильтрами, скрытием слов и разделов, добавлением своих карточек, копированием и сбросом. Настройки и словарь сохраняются локально.

Источник списка слов: приложенный PDF «Словарные-слова_Задание9.pdf» («Русский язык с Дарьей Устиновой», rus100ege). Пропускаемая буква для большинства исходных слов выбрана автоматически; перед использованием в качестве проверенного учебного банка задания требуют редакторской вычитки. Это тренировка слов из материала к заданию 9, а не симулятор официального формата ЕГЭ.
