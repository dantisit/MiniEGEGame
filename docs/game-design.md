# Геймдизайн тренажёра слов: по образцу `mainTask7.html`

**Основа:** [оригинальный HTML](reference/mainTask7.html), приложенный пользователем; файл сохранён **без изменений** как визуальный и функциональный образец. Он тренирует окончания существительных, а новое приложение должно тренировать правописание слов из приложенного PDF «Словарные-слова_Задание9.pdf». **Здесь нет нового дизайна «с нуля»: повторяем композицию, стиль и привычный сценарий исходной страницы, меняем только учебный материал и способы ответа там, где это необходимо для орфографии.** Это спецификация; первая рабочая версия доступна в корневом `index.html`.

## Что копируем из образца

| Вкладки «Тренировка» / «Словарь» | Сохраняем их назначение и добавляем третью вкладку «Статистика» по запросу пользователя. Без карты уровней, звёзд и нового главного экрана. |
| Настройки-флажки: включать скрытые, пользовательские, стандартные слова и скрытые разделы | Сохраняем фильтры; слова и тематические разделы берём из новой базы. Если разделов пока нет, не показываем бессмысленный флажок разделов. |

На лицевой стороне — контекст, после раскрытия — правильное написание и краткое пояснение. Варианты вроде этих не спрашиваем без контекста. |

Добавление нового слова требует проверяемого написания и задания (маска + вариант), а не старого формата окончаний «Слово(Ы/а)». |

## Как выглядит экран тренировки

```text
┌──────────────────────────────────────────────┐
│ Правописание слов. Задание 9                 │
│ Решено: 6/8                            75%  │
│ █████████░░░                                │
└──────────────────────────────────────────────┘
[        Тренировка       ][       Словарь     ]

┌ Настройки тренировки ────────────────────────┐
│ Не скрыто пропусков: 309                      │
│ ☑ стандартные  ☑ пользовательские  ☑ скрытые │
└──────────────────────────────────────────────┘

Выберите правильную букву в каждом слове.

┌──────────────────────────────────────────────┐
│               абон(е / и)мент               │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│                б(а / о)ссейн                 │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│                ап(е / и)лляция               │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│               пр(и / е)вилегия               │
└──────────────────────────────────────────────┘

[ Проверить ][ Продолжить ][ Особые случаи ][ Выбрать режим ]
                  Правильных ответов: 3 из 4
```

Это **схема расположения**, не готовый экран. Порядок вариантов меняется, но правописание и задания в базе проверяет редактор. Для слов с несколькими трудными позициями задаём отдельные карточки или ввод целого слова: не показываем маску, где отсутствует несколько букв, если выбор только один. При маленькой ширине четыре кнопки под заданиями переносятся на отдельные строки, как в образце.

## Основной цикл (как в исходном HTML)

1. Открывается вкладка «Тренировка» и случайная четвёрка карточек из включённых в настройках слов.
2. Пользователь выбирает ответ на каждой карточке; может изменить выбор до проверки.
3. Кнопка «Проверить» сравнивает все четыре ответа и окрашивает правильные и ошибочные карточки. Под каждой ошибкой видны правильное **слово целиком** и, если нужно, краткий контекст. Результат и процент в шапке обновляются один раз.
4. Кнопка «Продолжить» показывает следующую четвёрку. Когда доступных карточек меньше четырёх, показываем сколько есть; когда их нет — сообщение «Нет слов для тренировки. Измените фильтры или добавьте слово» вместо пустого экрана.
5. Во вкладке «Словарь» пользователь ищет, скрывает и возвращает отдельные пропуски, а также добавляет свои слова; настройки отражаются в следующей четвёрке. Пользовательские изменения сохраняются локально.

**Режим «Написать слово»:** сохраняем те же карточки, кнопку «Проверить», цветовую обратную связь и результат, но вместо двух кликабельных букв у каждой карточки — поле ввода; показываем ту же маску с одним пропуском и просим вписать слово целиком, не раскрывая ответ до проверки. Для «кампания/компания» и «касатка/косатка» контекст обязателен в обоих режимах. При сравнении убираем внешние пробелы и игнорируем регистр, но не исправляем автоматически внутренние ошибки и «ё» там, где она проверяется.

## Внешний вид: повторить, не переизобретать

В качестве источника размеров, цветов, скруглений и адаптивных правил использовать CSS из [образца](reference/mainTask7.html): `body` с фоном `#f8f9fa`, шапка `linear-gradient(135deg, #6a11cb 0%, #2575fc 100%)`, активная вкладка `#6a11cb`, синяя кнопка проверки `#3498db`, зелёная кнопка продолжения `#2ecc71`, фиолетовая кнопка особых случаев `#9b59b6`, оранжевая кнопка выбора режима `#e67e22`. После проверки — зелёные и красные состояния из исходника. Сохраняем крупные карточки, одностраничный интерфейс и модальные окна; не добавляем карту, маскота, валюту и другие элементы предыдущей концепции. Для новых полей ввода и интерактивных букв сделать заметный фокус и доступные подписи, не меняя визуальный язык.

## Данные и границы задачи

- PDF содержит отдельные слова, семейства слов и пометки смысла в скобках. Каждую проверяемую форму храним отдельно; родственные слова можно группировать в словаре. Пометки смысла становятся подсказками/контекстом, **не частью ответа**.
- Для каждого задания храним правильное слово, маску с одним пропуском и неверный вариант; верную букву получаем из слова в позиции пропуска. Для режима ввода используем ту же маску и ответ целиком. При необходимости добавляем однозначный контекст. Не создаём позиции или неверные варианты автоматически.
- Проверять слова из PDF — не то же самое, что воспроизводить официальный формат задания 9 ЕГЭ. Не переносить в новый тренажёр старые существительные и «особые случаи» окончаний из `mainTask7.html`.
- Не копируем JavaScript старого приложения как есть: он сравнивает **окончания** и содержит данные другой темы. Копируем **геймдизайн и интерфейсный сценарий**, а данные и логику проверки адаптируем к орфографии.
- Сейчас реализована страница с 454 отдельными упражнениями для 315 слов из нового пользовательского списка. В исходном PDF-словаре 538 словоформ для разделов и подсказок, но в выдачу попадают только слова и маски из новой TSV-таблицы. Из 455 строк исключён точный повтор маски «оранж_рея»; по согласованию исправлены неверная буква для «пар_докс» и написание маски «универс_тет». Два пустых флага скрытия приняты за `0`. У новых упражнений отдельное пространство идентификаторов, чтобы старые ответы не относились к другой таблице. Прогресс по дням и интервальные повторения пока не реализованы.

## Статистика (добавлена после согласования основного дизайна)

Отдельная вкладка показывает общий счёт и результаты **по каждому упражнению с пропуском**, даже если несколько пропусков относятся к одному слову. После каждой проверки считаем отдельно правильные ответы и ошибки; повторное нажатие «Проверить» не начисляет результат. КД = число правильных ответов / число ошибок. Если ошибок нет, но есть правильные ответы, показываем `∞`; если попыток ещё не было — `—`. Есть поиск по слову/маске, сортировка КД по возрастанию или убыванию, алфавитный порядок и фильтр «Только с попытками». КД носит только информационный характер: он **не управляет выбором заданий**, таймеров нет.

Результаты сохраняются в `localStorage` на данном устройстве и в данном браузере, без аккаунта и синхронизации. Общий счёт из прежней версии сохраняется, но его нельзя достоверно распределить по упражнениям: подробный учёт начинается с этого обновления. Отдельная кнопка сброса статистики с подтверждением не затрагивает словарь и настройки. Очистка данных браузера удалит результаты.

## Отдельные пропуски и скрытие жестом

Словарь отображает 454 упражнения отдельными строками (плюс пользовательские). 145 помечены скрытыми по умолчанию, поэтому сначала в тренировке доступны 309; сброс словаря возвращает именно эту исходную разметку. Для каждого из 24 пропусков удвоенной согласной неверный вариант — `!`. Кнопка «Скрыть» в строке действует только на соответствующую маску; другие пропуски того же слова остаются доступными. В тренировке для того же действия можно провести карточку **влево** или нажать доступную без жеста кнопку «Скрыть пропуск». При скрытии до проверки остальные уже выбранные ответы сохраняются; после проверки карточка остаётся до кнопки «Продолжить», но больше не выпадает в новых подходах. Над фильтрами тренировки показано, сколько пропусков ещё не скрыто: счётчик охватывает стандартные и пользовательские упражнения независимо от временных фильтров. Скрытые пропуски можно вернуть в словаре или включить их показ в настройках тренировки. Скрытие не изменяет накопленную статистику; ранее скрытые целиком слова при загрузке переводятся в набор скрытых пропусков.

## Дополнительные режимы (из присланных HTML)

Стартовая страница всегда предлагает пять вариантов: два для правописания, ударения и два для окончаний. Вся градиентная шапка кликабельна, она возвращает к выбору режима. Словарь и статистика переключаются вместе с режимом. Ударение выбирается нажатием на гласную; выбор окончания повторяет принцип оригинального mainTask7.html. Выдаётся до четырёх разных слов за раунд. Ошибки подсвечиваются, верный ответ раскрывается после проверки; статистика и скрытые записи сохраняются в браузере отдельно для каждого набора. Исходные материалы и точные количества описаны в README. В упражнениях по ударениям `Ё/ё` отображаются как `Е/е`, включая собственные слова пользователя; оригинальный файл-источник и режимы окончаний/орфографии сохраняют исходное написание.
