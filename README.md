# MiniEGEGame

Тренажёр правописания слов из приложенного PDF. Интерфейс повторяет [геймдизайн](docs/game-design.md) и стиль [образца `mainTask7.html`](docs/reference/mainTask7.html) (оригинал сохранён без изменений).

## Структура проекта

```text
MiniEGEGame/
├── index.html                  # точка входа: тренировка, словарь и статистика
├── src/
│   ├── app.js                  # упражнения, проверка, словарь, localStorage
│   ├── styles.css              # оформление и адаптивная вёрстка
│   └── data/
│       ├── words.js            # 538 словоформ из приложенного PDF
│       └── exercises.js        # 802 упражнения: маска и неверная буква
├── scripts/serve.mjs           # локальный статический сервер
├── tests/app.test.cjs          # автоматические проверки основных сценариев
├── docs/
│   ├── game-design.md          # спецификация тренажёра
│   └── reference/mainTask7.html # неизменённый образец интерфейса
├── package.json               # команды запуска и тестов
└── package-lock.json          # фиксированные версии тестовых зависимостей
```

Исходники не требуют сборки: `index.html` подключает `src/styles.css`, `src/data/words.js`, `src/data/exercises.js` и `src/app.js`. Для **работы приложения** устанавливать пакеты не нужно; `npm install` нужен только для тестов.

## Запуск

При наличии Node.js:

```sh
npm start
```

Откройте `http://localhost:8000/`. Для другого порта задайте переменную окружения `PORT` (например, PowerShell: `$env:PORT=8080; npm start`). Альтернативно можно использовать `python3 -m http.server 8000` (в Windows: `py -m http.server 8000`).

## Тесты

```sh
npm ci
npm test
```

Проверяются данные словаря, соответствие каждого из 802 пропусков исходному слову, оба режима, статистика по пропускам, КД, сортировка, сохранение данных, пользовательские слова и пустая выборка.

## Возможности и ограничения

- 538 словоформ и 802 отдельных упражнения с пропусками по присланной таблице-скриншоту (запись «фигурист(ка)» развёрнута в две формы). Каждый пропуск и неверная буква указаны явно; автоматического выбора позиции нет. По четыре разных слова за подход; выбор буквы или ввод слова по той же маске.
- Проверка с подсветкой, подсказки для смысловых пар, модальное окно особых случаев.
- Вкладка «Статистика»: общий счёт, правильные ответы и ошибки для **каждого отдельного пропуска**, КД (правильные ÷ ошибки), поиск и сортировка по КД. Без ошибок КД = ∞, без попыток — «—». Статистика ничего не меняет в случайной выдаче заданий.
- Словарь показывает **каждый пропуск отдельной строкой**: можно искать, скрывать или возвращать конкретное упражнение, а также скрывать разделы, добавлять свои карточки, копировать и сбрасывать словарь. В тренировке пропуск скрывается свайпом карточки влево или кнопкой «Скрыть пропуск»; остальные ответы в текущей четвёрке сохраняются. Скрытый пропуск не выпадает снова, пока не включён показ скрытых упражнений или он не возвращён через словарь.
- Настройки словаря, скрытые пропуски и статистика сохраняются в `localStorage` этого браузера на этом устройстве (без синхронизации). Ранее скрытые целиком слова при обновлении превращаются в скрытые пропуски; прежний общий счёт сохраняется. Очистка данных сайта удалит результаты.

Источник списка слов: приложенный PDF «Словарные-слова_Задание9.pdf» («Русский язык с Дарьей Устиновой», rus100ege). Разметка пропусков и неверных букв перенесена с присланного пользователем скриншота таблицы: 801 строка, запись «фигурист(ка)» разделена на две формы. Все маски сверены программно со словами; из-за исходного формата изображения перед публикацией как проверенного учебного банка желательна окончательная вычитка человеком. Это тренировка слов из материала к заданию 9, а не симулятор официального формата ЕГЭ.
