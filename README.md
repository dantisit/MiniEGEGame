# MiniEGEGame

Тренажёр правописания слов из приложенного PDF. Интерфейс повторяет [геймдизайн](docs/game-design.md) и стиль [образца `mainTask7.html`](docs/reference/mainTask7.html) (оригинал сохранён без изменений).

## Структура проекта

```text
MiniEGEGame/
├── index.html                  # точка входа: экраны тренировки и словаря
├── src/
│   ├── app.js                  # упражнения, проверка, словарь, localStorage
│   ├── styles.css              # оформление и адаптивная вёрстка
│   └── data/words.js           # 538 словоформ из приложенного PDF
├── scripts/serve.mjs           # локальный статический сервер
├── tests/app.test.cjs          # автоматические проверки основных сценариев
├── docs/
│   ├── game-design.md          # спецификация тренажёра
│   └── reference/mainTask7.html # неизменённый образец интерфейса
├── package.json               # команды запуска и тестов
└── package-lock.json          # фиксированные версии тестовых зависимостей
```

Исходники не требуют сборки: `index.html` подключает `src/styles.css`, `src/data/words.js` и `src/app.js`. Для **работы приложения** устанавливать пакеты не нужно; `npm install` нужен только для тестов.

## Запуск

При наличии Node.js:

```sh
npm start
```

Откройте `http://localhost:8000/`. Для другого порта задайте переменную окружения `PORT` (например, PowerShell: `$env:PORT=8080; npm start`). Альтернативно можно использовать `python3 -m http.server 8000` (в Windows: `py -m http.server 8000`).

## Тесты

```sh
npm ci
npm test
```

Проверяются данные словаря, оба режима, статистика, сохранение данных, пользовательские слова и пустая выборка.

## Возможности и ограничения

- 538 словоформ из списка (включая «фигурист» и «фигуристка» из записи «фигурист(ка)»), по четыре карточки за подход; выбор буквы или ввод слова по маске.
- Проверка с подсветкой и статистикой, подсказки для смысловых пар, модальное окно особых случаев.
- Словарь с поиском, фильтрами, скрытием слов и разделов, добавлением своих карточек, копированием и сбросом. Настройки и словарь сохраняются локально в браузере.

Источник списка слов: приложенный PDF «Словарные-слова_Задание9.pdf» («Русский язык с Дарьей Устиновой», rus100ege). Пропускаемая буква для большинства слов выбрана автоматически; перед использованием как проверенного учебного банка задания требуют редакторской вычитки. Это тренировка слов из материала к заданию 9, а не симулятор официального формата ЕГЭ.
