# Геймдизайн тренажёра слов: по образцу `mainTask7.html`

**Основа:** [оригинальный HTML](reference/mainTask7.html), приложенный пользователем; файл сохранён **без изменений** как визуальный и функциональный образец. Он тренирует окончания существительных, а новое приложение должно тренировать правописание слов из приложенного PDF «Словарные-слова_Задание9.pdf». **Здесь нет нового дизайна «с нуля»: повторяем композицию, стиль и привычный сценарий исходной страницы, меняем только учебный материал и способы ответа там, где это необходимо для орфографии.** Это спецификация; первая рабочая версия доступна в корневом `index.html`.

## Что копируем из образца

| Элемент `mainTask7.html` | В тренажёре слов |
| --- | --- |
| Одна адаптивная страница: светло-серый фон, центрированный контейнер до 800 px, белые карточки, скругления и мягкие тени | Сохраняем композицию и визуальные параметры; на узком экране элементы выстраиваются столбцом, как в исходнике. |

| Две вкладки «Тренировка» / «Словарь» | Те же вкладки с теми же назначениями. Без карты уровней, звёзд и нового главного экрана. |
| Настройки-флажки: включать скрытые, пользовательские, стандартные слова и скрытые разделы | Сохраняем фильтры; слова и тематические разделы берём из новой базы. Если разделов пока нет, не показываем бессмысленный флажок разделов. |

| После проверки зелёная/красная подсветка карточек и вариантов, общий результат «N из 4», кнопка «Продолжить» | Сохраняем в точности сценарий: показываем верную букву и слово целиком, неверный вариант — красным; затем новая четвёрка слов. Не сбрасываем проверенную четвёрку повторным нажатием. |
| «Особые случаи» в модальном окне с раскрывающимися карточками | Карточки пар с зависимостью написания от смысла: **кампания / компания**, **касатка / косатка**. На лицевой стороне — контекст, после раскрытия — правильное написание и краткое пояснение. Варианты вроде этих не спрашиваем без контекста. |
| «Выбрать режим» в модальном окне карточек режимов | «Выбор буквы» (основной режим) и «Написать слово» (режим самостоятельного ввода). Смена режима обновляет заголовок и упражнения, но не уничтожает пользовательский словарь. Если реализован только один режим, кнопку выбора не показываем. |
| Вкладка «Словарь»: поиск, «Показать все», «Только скрытые», «Только пользовательские», скрытие/удаление, свёртка разделов, копирование, сброс и форма добавления | Те же инструменты управления. Списки показывают правильное слово и трудную позицию, при необходимости — значение/подсказку. Добавление нового слова требует проверяемого написания и задания (маска + варианты либо контекст для ввода), а не старого формата окончаний «Слово(Ы/а)». |

## Как выглядит экран тренировки

```text
┌──────────────────────────────────────────────┐
│ Правописание слов. Задание 9                 │
│ Решено: 6/8                            75%  │
│ █████████░░░                                │
└──────────────────────────────────────────────┘
[        Тренировка       ][       Словарь     ]

┌ Настройки тренировки ────────────────────────┐
│ ☑ стандартные  ☑ пользовательские  ☑ скрытые │
└──────────────────────────────────────────────┘

Выберите правильную букву в каждом слове.

┌──────────────────────────────────────────────┐
│               аб(о / а)немент               │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│                басс(е / и)йн                 │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│                ап(е / и)лляция               │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│               пр(и / е)вилегия               │
└──────────────────────────────────────────────┘

[ Проверить ][ Продолжить ][ Особые случаи ][ Выбрать режим ]
                  Правильных ответов: 3 из 4
```

Это **схема расположения**, не готовый экран. Порядок вариантов меняется, но правописание и задания в базе проверяет редактор. Для слов с несколькими трудными позициями задаём отдельные карточки или ввод целого слова: не показываем маску, где отсутствует несколько букв, если выбор только один. При маленькой ширине четыре кнопки под заданиями переносятся на отдельные строки, как в образце.

## Основной цикл (как в исходном HTML)

1. Открывается вкладка «Тренировка» и случайная четвёрка карточек из включённых в настройках слов.
2. Пользователь выбирает ответ на каждой карточке; может изменить выбор до проверки.
3. Кнопка «Проверить» сравнивает все четыре ответа и окрашивает правильные и ошибочные карточки. Под каждой ошибкой видны правильное **слово целиком** и, если нужно, краткий контекст. Результат и процент в шапке обновляются один раз.
4. Кнопка «Продолжить» показывает следующую четвёрку. Когда доступных карточек меньше четырёх, показываем сколько есть; когда их нет — сообщение «Нет слов для тренировки. Измените фильтры или добавьте слово» вместо пустого экрана.
5. Во вкладке «Словарь» пользователь ищет, скрывает, добавляет и возвращает слова; настройки отражаются в следующей четвёрке. Пользовательские изменения сохраняются локально.

**Режим «Написать слово»:** сохраняем те же карточки, кнопку «Проверить», цветовую обратную связь и результат, но вместо двух кликабельных букв у каждой карточки — поле ввода; даём определение или предложение с пропуском, чтобы не показывать целевое слово до ответа. Для «кампания/компания» и «касатка/косатка» контекст обязателен в обоих режимах. При сравнении убираем внешние пробелы и игнорируем регистр, но не исправляем автоматически внутренние ошибки и «ё» там, где она проверяется.

## Внешний вид: повторить, не переизобретать

В качестве источника размеров, цветов, скруглений и адаптивных правил использовать CSS из [образца](reference/mainTask7.html): `body` с фоном `#f8f9fa`, шапка `linear-gradient(135deg, #6a11cb 0%, #2575fc 100%)`, активная вкладка `#6a11cb`, синяя кнопка проверки `#3498db`, зелёная кнопка продолжения `#2ecc71`, фиолетовая кнопка особых случаев `#9b59b6`, оранжевая кнопка выбора режима `#e67e22`. После проверки — зелёные и красные состояния из исходника. Сохраняем крупные карточки, одностраничный интерфейс и модальные окна; не добавляем карту, маскота, валюту и другие элементы предыдущей концепции. Для новых полей ввода и интерактивных букв сделать заметный фокус и доступные подписи, не меняя визуальный язык.

## Данные и границы задачи

- PDF содержит отдельные слова, семейства слов и пометки смысла в скобках. Каждую проверяемую форму храним отдельно; родственные слова можно группировать в словаре. Пометки смысла становятся подсказками/контекстом, **не частью ответа**.
- Для выбора буквы нужны: правильное слово, маска, проверяемая позиция, верный и неверный вариант, при необходимости контекст. Для режима ввода нужны определение/предложение и допустимый ответ. Исключить спорные и непроверенные автоматически составленные задания.
- Проверять слова из PDF — не то же самое, что воспроизводить официальный формат задания 9 ЕГЭ. Не переносить в новый тренажёр старые существительные и «особые случаи» окончаний из `mainTask7.html`.
- Не копируем JavaScript старого приложения как есть: он сравнивает **окончания** и содержит данные другой темы. Копируем **геймдизайн и интерфейсный сценарий**, а данные и логику проверки адаптируем к орфографии.
- В первой версии реализованы рабочая страница и импорт 538 форм из PDF (включая две формы из «фигурист(ка)»). Позиции для выбора буквы в большинстве слов подбираются автоматически, поэтому перед использованием как проверенного учебного банка нужна редакторская вычитка заданий. Прогресс по дням и интервальные повторения пока не реализованы.
