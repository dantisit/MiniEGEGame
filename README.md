# MiniEGEGame

Тренажёр слов: правописание из PDF, ударения из [mainORF.html](docs/reference/mainORF.html) и окончания из [mainTask7.html](docs/reference/mainTask7.html). Интерфейс опирается на [геймдизайн](docs/game-design.md). Оба исходных HTML-файла сохранены без изменений.

## Структура проекта

```text
MiniEGEGame/
├── index.html                  # выбор режима, тренировка, словарь и статистика
├── src/
│   ├── app.js                  # орфография, навигация и выбор режима
│   ├── extra-modes.js          # ударения и окончания: тренировка, словарь, статистика
│   ├── styles.css              # оформление и адаптивная вёрстка
│   └── data/
│       ├── words.js            # 538 словоформ из приложенного PDF
│       └── exercises.js        # исправленная таблица: 783 активные маски и вариант ответа
│       └── extra-modes.js      # 201 ударение, 83 + 163 окончания
├── scripts/serve.mjs           # локальный статический сервер
├── tests/app.test.cjs          # автоматические проверки основных сценариев
├── docs/
│   ├── game-design.md          # спецификация тренажёра
│   └── reference/             # неизменённые оригиналы mainTask7.html и mainORF.html
├── package.json               # команды запуска и тестов
└── package-lock.json          # фиксированные версии тестовых зависимостей
```

Исходники не требуют сборки: `index.html` подключает `src/styles.css`, `src/data/words.js`, `src/data/exercises.js`, `src/data/extra-modes.js`, `src/extra-modes.js` и `src/app.js`. Для **работы приложения** устанавливать пакеты не нужно; `npm install` нужен только для тестов.

## Запуск

При наличии Node.js:

```sh
npm start
```

Откройте `http://localhost:8000/`. Для другого порта задайте переменную окружения `PORT` (например, PowerShell: `$env:PORT=8080; npm start`). Альтернативно можно использовать `python3 -m http.server 8000` (в Windows: `py -m http.server 8000`).

## Тесты

```sh
npm ci
npm test
```

Проверяются данные словарей, соответствие масок словам, исправленные строки таблицы, вариант `!` для удвоенных согласных, пять режимов, стартовый экран, статистика по пропускам, КД, сохранение данных и пустая выборка.

## Режимы и навигация

При **каждом** открытии сайта показывается выбор режима, даже если на устройстве сохранён предыдущий выбор. Градиентная шапка — кнопка возврата на экран выбора; при выборе того же режима можно продолжить незавершённое задание. Вкладки «Тренировка», «Словарь» и «Статистика» относятся к выбранному режиму.

- **Правописание**: выбор буквы или написание слова из PDF и пользовательской разметки; оба варианта используют один словарь и общую статистику по пропускам.
- **Ударения**: 201 уникальная запись из `mainORF.html` (в исходнике 202, «красИвее» повторяется). Нажимайте на ударную гласную. В словаре ударная гласная показана прописной. **Только в этом режиме** все `Ё/ё` заменены на `Е/е` (включая ранее добавленные и новые пользовательские слова); исходный HTML и задания других режимов не меняются. Два варианта «отзыв» различаются подсказками.
- **Окончания**: 83 записи для именительного и 163 для родительного падежа множественного числа из `mainTask7.html`. Выбирайте правильное окончание; «▢» означает отсутствие окончания. Категории и смысловые подсказки исходника сохранены.

Для каждого из трёх новых режимов доступны свой словарь с поиском, скрытием отдельных записей, добавлением своих слов и своя статистика (правильные, ошибки, КД). Скрыть карточку можно свайпом влево или кнопкой. Данные этих режимов сохраняются отдельно в `localStorage` (`miniege-extra-v1`), орфография — в `miniege-spelling-v1`; очистка данных сайта удалит результаты. Изменения в одной теме не влияют на статистику других.

## Возможности и ограничения

- Исходный PDF содержит 538 словоформ. В исправленной таблице осталось **783 действующих пропуска для 535 слов**: 19 строк очищены, а запись «фигурист(ка)» развёрнута в две формы. Идентификаторы неизменённых строк сохранены; шесть исправленных масок получили новые идентификаторы, чтобы прежние ответы и скрытие не привязались к другой букве. Позиции и варианты ответов берутся из исправленной таблицы; во всех 35 заданиях на удвоенную согласную неверный вариант — `!`. По четыре разных слова за подход; выбор буквы или ввод слова по той же маске.
- Проверка с подсветкой, подсказки для смысловых пар, модальное окно особых случаев.
- Вкладка «Статистика»: общий счёт, правильные ответы и ошибки для **каждого отдельного пропуска**, КД (правильные ÷ ошибки), поиск и сортировка по КД. Без ошибок КД = ∞, без попыток — «—». Статистика ничего не меняет в случайной выдаче заданий.
- Словарь показывает **каждый пропуск отдельной строкой**: можно искать, скрывать или возвращать конкретное упражнение, а также скрывать разделы, добавлять свои карточки, копировать и сбрасывать словарь. В тренировке пропуск скрывается свайпом карточки влево или кнопкой «Скрыть пропуск»; остальные ответы в текущей четвёрке сохраняются. Скрытый пропуск не выпадает снова, пока не включён показ скрытых упражнений или он не возвращён через словарь.
- Настройки словаря, скрытые пропуски и статистика сохраняются в `localStorage` этого браузера на этом устройстве (без синхронизации). Ранее скрытые целиком слова при обновлении превращаются в скрытые пропуски; прежний общий счёт сохраняется. Очистка данных сайта удалит результаты.

Источник списка слов: приложенный PDF «Словарные-слова_Задание9.pdf» («Русский язык с Дарьей Устиновой», rus100ege). Разметка перенесена из новой таблицы-скриншота: 801 строка, 19 из них очищены; запись «фигурист(ка)» разделена на две формы. Шесть изменённых масок и новые варианты сверены с изображением, все действующие маски программно проверены на совпадение со словом. Из-за исходного формата изображения перед публикацией как проверенного учебного банка желательна окончательная вычитка человеком. Это тренировка слов из материала к заданию 9, а не симулятор официального формата ЕГЭ.
